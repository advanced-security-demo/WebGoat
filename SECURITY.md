# Security Policy

WebGoat is intentionally vulnerable and is designed for security training. Vulnerabilities that are part of the lessons are expected behavior, not security defects. Run WebGoat only in a controlled environment and do not expose it to untrusted networks.

## Supported Versions

We provide security fixes for the latest stable release only.

| Version | Supported |
| --- | --- |
| Latest stable release | :white_check_mark: |
| Older releases and development snapshots | :x: |

## Reporting a Vulnerability

Please do not report security issues in public GitHub issues or discussions. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Include the affected version, impact, and steps to reproduce.

If private reporting is unavailable, contact the project maintainers through a confirmed security contact.
